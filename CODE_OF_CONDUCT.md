# Code of conduct

svgworm follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to issues, pull requests, discussions, and any other project space.

## Reporting

Report unacceptable behavior to the maintainer, [@jmlweb](https://github.com/jmlweb), by email at the address on their GitHub profile. Reports are kept confidential.
