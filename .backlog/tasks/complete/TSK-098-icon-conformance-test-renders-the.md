# Icon conformance test renders the current init Icon.astro template

## Description

apps/site/tests/icon-conformance.test.ts renders the site's committed Icon.astro, generated by an older init (manifest v1 only, no crossOrigin inject path). The template init writes today (astroComponentContent in packages/svgworm/src/cli/init/plan.ts) is only string-matched in plan.test.ts, so a markup regression in it would pass CI. Fix: the conformance test renders the template from plan.ts, the site's Icon.astro is regenerated, and a test fails when the committed copy drifts from the template.
