@svgworm/react is published and may not import svgworm (ADR-0008), and it cannot import a file from the user's moduleDir either. So any "shared delivery helper" generated by the build only reaches the init-generated Icon.astro/.vue/.svelte; React would need a new createIcon(manifest, helper) API. A moduleDir helper also couples a file every build rewrites with Icon files that init writes once and the user then owns, so its API would need versioning. ADR-0037 keeps four renderers guarded by the conformance tests and shares only the byte-identical manifest types in plan.ts (ICON_MANIFEST_TYPES). To refactor a template safely, render every *ComponentContent/*LoaderContent output before and after and diff -r: byte-identical output means no changeset and no conformance change.
