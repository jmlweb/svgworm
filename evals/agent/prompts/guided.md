Add the icons from `icons/` to `app/page.tsx` using **svgworm** (https://github.com/jmlweb/svgworm, read its `llms.txt` and `skills/svgworm-nextjs/SKILL.md` if you need details): each nav link gets its UI icon before the text, and each "Built with" badge gets its brand icon. Requirements: the page must stay a Server Component with no client JavaScript for the icons, brand icons keep their colors, UI icons follow the text color, and `pnpm build` must pass. Install whatever you need with pnpm. Do not change the README.
