# Acme dashboard

Next.js 16 App Router app. Icons exported from the design tool live in `icons/`:

- `icons/ui/home.svg`, `house.svg`, `github.svg`, `close.svg`: UI icons for the nav links on the home page
- `icons/brand/kotlin.svg`, `nextjs.svg`, `about.svg`: brand badges (keep their colors)
- `icons/café.svg`: the coffee badge

Package manager: pnpm. `pnpm build` must pass.
